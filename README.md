# 🍼 MomStore — Интернет-магазин товаров для мам и малышей

Современный, быстрый и адаптивный интернет-магазин, разработанный с использованием React (Vite) на клиенте и Node.js (Express) + PostgreSQL на сервере. Проект полностью контейнеризован с помощью Docker для быстрого развертывания.

## ✨ Ключевые возможности

### Для покупателей (Пользователей)
* **Каталог товаров:** Просмотр доступных товаров с фотографиями, описанием, ценой и актуальным количеством на складе.
* **Живой поиск (Smart Search):** Поиск товаров работает "на лету" с красивым выпадающим меню предпросмотра (как на маркетплейсах).
* **Умная корзина:** Добавление товаров в корзину с жесткой проверкой остатков на складе. Система не даст добавить больше товаров, чем есть в наличии.
* **Оформление заказа:** Полноценный флоу покупки со списанием остатков со склада базы данных.
* **Личный профиль:** История заказов с сохранением "слепков" (snapshots) покупок. Если администратор удалит товар из магазина, он всё равно навсегда останется в истории заказов пользователя с картинкой и ценой на момент покупки.
* **Авторизация:** Безопасная регистрация и вход на базе JWT (JSON Web Tokens).

### Для администратора
* **Панель управления (CMS):** Защищенный раздел для управления витриной.
* **Управление товарами (CRUD):** Создание, редактирование и удаление карточек товаров с интерактивными предупреждениями.
* **Загрузка медиа:** Возможность прикреплять к товарам как ссылки на картинки из интернета, так и загружать локальные фотографии прямо с компьютера (через `multer`).

## 🚀 Как запустить проект локально

Проект настроен для максимально простого запуска через Docker. Вам не нужно локально устанавливать Node.js или PostgreSQL.

### Требования
* Установленный **Docker** и **Docker Compose**.

### Шаги по запуску

1. Склонируйте репозиторий:
   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
   cd mum_store1

2. Запустите сборку и старт контейнеров:
   ```bash
   docker-compose up --build

Дождитесь, пока база данных инициализируется, а сервера запустятся.

Откройте приложение в браузере:
* **Клиентская часть:** http://localhost:5173
* **API бэкенда:** http://localhost:5000

*Примечание: База данных автоматически инициализируется тестовыми товарами при первом запуске (через `db/init.sql`).*
